# Firmware

This directory is reserved for Robot 88 embedded firmware.

CoreS3 firmware work has been used for audio capture, Wi-Fi communication, and speaker playback experiments. The actual firmware source has not yet been added to this public repository.

Before publishing source, remove credentials and device-specific secrets; document the exact board, ESP-IDF version, verified pin mappings, build and flash instructions, power requirements, test procedure, and known limitations.
